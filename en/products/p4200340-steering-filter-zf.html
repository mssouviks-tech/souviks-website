Description

Description

The Leyparts P4200340 steering filter element is designed for compatible ZF hydraulic power-steering systems. It filters circulating steering fluid to help capture contaminants and protect components within the hydraulic steering circuit. Compatible vehicle references: Ashok Leyland Ecomet, Ashok Leyland U-Truck.
