# Agent Protocol Discovery

Use the standard discovery endpoints published by Souviks.

## Discovery resources

- API catalog: https://www.souviks.co.in/.well-known/api-catalog
- A2A Agent Card: https://www.souviks.co.in/.well-known/agent-card.json
- MCP Server Card: https://www.souviks.co.in/.well-known/mcp/server-card.json
- OAuth/OIDC discovery: https://www.souviks.co.in/.well-known/openid-configuration
- OAuth Protected Resource Metadata: https://www.souviks.co.in/.well-known/oauth-protected-resource
- Auth guidance: https://www.souviks.co.in/auth.md

Follow the protocol-specific discovery document before invoking an interface.
