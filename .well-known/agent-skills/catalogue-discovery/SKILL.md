# Catalogue Discovery

Use the Souviks public catalogue resources to discover products, brands, categories, vehicle applications, and search data.

## Primary resources

- Products: https://www.souviks.co.in/assets/data/products.json
- Brands: https://www.souviks.co.in/assets/data/brands.json
- Categories: https://www.souviks.co.in/assets/data/categories.json
- Vehicles: https://www.souviks.co.in/assets/data/vehicles.json
- Search index: https://www.souviks.co.in/assets/data/search.json
- Human catalogue: https://www.souviks.co.in/en/products.html

Prefer the machine-readable JSON resources for structured discovery. Treat product data as the source of catalogue facts and do not invent stock, pricing, compatibility, or availability that is not present in the data.
